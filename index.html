Sem essas variáveis, o botão mostra que o login oficial ainda não está configurado; não existe login simulado. ## Registrar a aplicação No Creator Dashboard, crie um app OAuth 2.0. Escolha apenas os escopos de identidade `openid` e `profile`; o site não precisa de acesso a jogos, grupos, inventário ou publicação. Configure uma URL de retorno HTTPS com este caminho: ```text https://SEU-DOMINIO-PUBLICADO/api/roblox/oauth/callback ``` O domínio/caminho precisam coincidir exatamente com `ROBLOX_REDIRECT_URI` configurado no servidor. Para testes locais, a documentação do Roblox permite redirect em localhost, por exemplo `http://localhost:3000/api/roblox/oauth/callback`. ## Segredos do backend Configure estes valores como variáveis protegidas do servidor, nunca dentro do frontend nem em um commit do GitHub: ```text ROBLOX_CLIENT_ID=ID_DO_APP ROBLOX_CLIENT_SECRET=SEGREDO_DO_APP ROBLOX_REDIRECT_URI=https://SEU-DOMINIO-PUBLICADO/api/roblox/oauth/callback ROBLOX_COOKIE_SECURE=true ``` No preview HTTPS e na publicação, mantenha `ROBLOX_COOKIE_SECURE=true`. Para testar apenas em HTTP local, use `false` e localhost; volte para `true` em qualquer domínio HTTPS. Depois de configurar os valores, reinicie o servidor. A aplicação OAuth recém-criada pode ficar em modo privado com limite de 10 usuários únicos até passar pela análise do Roblox. A documentação do Roblox também pede informações de privacidade/termos e um vídeo demonstrando todo o fluxo para solicitar publicação ampla. ## O que o site faz O login é iniciado no domínio oficial do Roblox. O site recebe de volta um código OAuth e o troca no backend com PKCE; não vê nem encaminha a senha. A opção de bio usa chamadas server-side aos domínios oficiais de usuários e miniaturas do Roblox, consulta a bio atual e compara o código temporário de cinco minutos. O projeto não pede cookies Roblox, não guarda access/refresh tokens e não precisa de chave Open Cloud para o fluxo público de perfil. ## Referências oficiais - [Visão geral OAuth 2.0 do Roblox](https://create.roblox.com/docs/cloud/auth/oauth2-overview): authorization code e PKCE; autorização ocorre no Roblox sem compartilhar credenciais com o app. - [Registro de apps OAuth](https://create.roblox.com/docs/cloud/auth/oauth2-registration): cadastro de client ID/secret, escopos `openid`/`profile`, redirect URLs HTTPS e modo privado de até 10 usuários únicos antes de análise para publicação ampla. - [Referência de endpoints OAuth](https://create.roblox.com/docs/cloud/auth/oauth2-reference): `/v1/authorize`, `/v1/token` e `/v1/userinfo` em `https://apis.roblox.com/oauth`. - [Referência oficial Users](https://create.roblox.com/docs/cloud/reference/features/users): lookup por nome/ID, perfis públicos e thumbnails. startServer().catch(error => { console.error(error); process.exit(1); }); }; } export async function cancelBioChallenge(challengeId: string) { if (/^[A-Za-z0-9_-]{40,50}$/.test(challengeId)) { await deleteBioChallenge(sha256Hex(challengeId)); } }
